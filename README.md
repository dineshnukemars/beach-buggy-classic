# Beach Buggy Classic

Browser arcade beach-buggy racer (Beach Buggy–inspired). **Local singleplayer + AI** for now.

## Run locally

```bash
npm install
npm run dev
```

Open the URL Vite prints (default http://localhost:5173).

## Controls

| Key | Action |
|-----|--------|
| Arrow keys / WASD | Steer, accelerate, brake |
| Space | Boost |
| R | Restart race |
